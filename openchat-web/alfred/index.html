      Operator brief
      
    
    
    
    Intelligence is not authority.
    
    
    The free OpenChat models run the planner and verifier. They never see the signing key. Every proposal crosses a deterministic engine.
    
    
    
      
    PlanUntrusted proposal
    The model proposes one tool call at a time.
    
      
    PolicyDeterministic decision
    Intent, scope, source, sensitivity, destination, flow, impact, permission.
    
      
    CapabilitySigned and single-use
    Five minutes, exact args, exact destination. The model cannot mint one.
    
      
    GatewayRe-checked before effect
    Signature, task, action, hash and destination. No bypass.
